# Taxi Ledger 3.0

Web app/PWA responsive per gestire incassi, spese pagate e pianificate, turni, ferie e consuntivo.

## Novità della versione

- Incassi e Spese con viste Giorno, Mese e Anno.
- Calendari mensili con colori per tipologia/categoria e totale giornaliero.
- Spese future visibili nella vista annuale e contrassegnate come Pianificate.
- Stato di una nuova spesa proposto automaticamente: Pagata per oggi/passato, Pianificata per date future.
- Nel Cruscotto, “Vedi tutti” è sostituito da “Vedi tutti gli incassi” e “Vedi tutte le spese”; il periodo attivo viene mantenuto nella sezione di destinazione.
- Dati separati per profilo locale, backup JSON, modalità PWA/offline.

## Pubblicazione GitHub Pages

Caricare nella root del repository tutti i file di questa cartella. In Settings → Pages scegliere `Deploy from a branch`, branch `main`, cartella `/(root)`.

## Installazione su iPhone

Aprire il sito con Safari, toccare Condividi e poi “Aggiungi alla schermata Home”.

> Gli account e i dati sono locali al browser. Per la sincronizzazione fra dispositivi occorre collegare un backend autenticato.
